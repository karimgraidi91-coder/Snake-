# Build Commands for Three Versions of Snake Battle

## Prerequisites
```
flutter clean
flutter pub get
```

---

## Version 1: APK Debug (No Ads) - Testing Build

**Command:**
```bash
flutter build apk --flavor debug --debug --target-platform android-arm64 --split-per-abi
```

**Output:**
```
build/app/outputs/flutter-apk/app-debug.apk
```

**Description:**
- Pure game code without any advertisements
- ARM64 architecture for most modern Android devices
- Debug build for testing and development
- Fastest compilation time
- No optimization applied

**Install on Device:**
```bash
adb install build/app/outputs/flutter-apk/app-debug.apk
```

---

## Version 2: APK Release (Yandex Ads)

**Command:**
```bash
flutter build apk --flavor yandex --release --target-platform android-arm64 --split-per-abi
```

**Output:**
```
build/app/outputs/flutter-apk/app-yandex-release.apk
```

**Description:**
- Integrated Yandex Mobile Ads
- Banner ads appear at bottom of screen during gameplay
- Interstitial ads show when player loses (Game Over)
- Rewarded video ads for bonus points (optional)
- Release build with code optimization
- Smaller file size than debug build
- Suitable for distribution on Yandex.Kassa or other Russian app stores

**Ad Unit IDs Configured:**

- Interstitial Ad Unit: 240845808
- Rewarded Ad Unit: 240845809

**Install on Device:**
```bash
adb install build/app/outputs/flutter-apk/app-yandex-release.apk
```

## Version 3: AAB Release (Google AdMob - Google Play)

**Command:**
```bash
flutter build appbundle --flavor admob --release --target-platform android-arm64
```

**Output:**
```
build/app/outputs/bundle/admobRelease/app-admob-release.aab
```

**Description:**
- Integrated Google Mobile Ads (AdMob)
- Multiple ad formats supported:
  - Banner Ads (bottom of screen)
  - Interstitial Ads (Game Over)
  - Rewarded Video Ads (bonus points)
  - Native Ads (optional)
  - App Open Ads (on app launch)
- App Bundle format optimized for Google Play Store
- Smaller downloads for end users (dynamic feature delivery)
- Release build with maximum optimization
- Code obfuscation with ProGuard
- Requires signing with production keystore

**Ad Unit IDs Configured:**

## Advanced Build Options

### Split APKs by Architecture (Multiple APKs)
```bash
# For Version 1 (Debug)
flutter build apk --flavor debug --debug --split-per-abi

# For Version 2 (Yandex)
flutter build apk --flavor yandex --release --split-per-abi

# For Version 3 (AdMob) - Use AAB instead
flutter build appbundle --flavor admob --release
```

### Universal APK (Single APK for all architectures)
```bash
# For Version 1 (Debug)
flutter build apk --flavor debug --debug

# For Version 2 (Yandex)
flutter build apk --flavor yandex --release

# For Version 3 (AdMob) - Not recommended
flutter build apk --flavor admob --release
```

### Build with Custom Version Code/Name
```bash
flutter build apk \
  --flavor yandex \
  --release \
  --build-number=2 \
  --build-name=1.0.1
```

## Testing Builds

### Verify APK Signature
```bash
jarsigner -verify build/app/outputs/flutter-apk/app-yandex-release.apk
```

### Check APK Contents
```bash
aapt dump badging build/app/outputs/flutter-apk/app-debug.apk
```

### Test on Emulator
```bash
# List available emulators
emulator -list-avds

# Start emulator
emulator -avd <emulator_name>

# Install APK
adb install build/app/outputs/flutter-apk/app-debug.apk

# Launch app
adb shell am start -n com.karim971210.snake_battle.debug/com.karim971210.snake_battle.MainActivity
```

## Troubleshooting

### Build Fails - Dependency Issues
```bash
flutter clean
flutter pub get
flutter pub cache clean --expired
```

### Gradle Sync Issues
```bash
cd android
./gradlew clean build
cd ..
```

### Memory Issues During Build
```bash
# Increase Gradle memory
export GRADLE_OPTS="-Xmx2048m -XX:MaxPermSize=512m"
```

### Android SDK Issues
```bash
flutter doctor
flutter doctor -v
```

## Build Flavors Configuration

All build flavors are configured in `android/app/build.gradle`:

```gradle
flavorDimensions "version"

productFlavors {
    debug {
        // No ads - testing
    }
    yandex {
        // Yandex Mobile Ads
    }
    admob {
        // Google Mobile Ads
    }
}
```

Each flavor has its own:
- Application ID suffix
- Version name suffix
- Build config variables
- Resource strings
